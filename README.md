# QA Check List

Chrome-расширение для QA-инженера: чек-листы в **Side Panel**, прохождение тестирования и экспорт результатов локально — без Google Sheets API и без Jira API.

## Что это

**QA Check List** — локальный Test Runner в боковой панели Chrome. Создаёте чек-лист прямо в расширении, отмечаете статусы во время тестирования сайта, добавляете комментарии / замечания / вопросы / баги, затем копируете результат в Excel или Jira.

Все данные хранятся только в `chrome.storage.local` на вашем компьютере.

## Возможности

- создание нескольких тестирований (Test Run);
- вложенные пункты чек-листа с автонумерацией (`1`, `1.1`, `2.1.1`);
- режимы **Редактирование** и **Тестирование**;
- статусы: Пройдено / Не пройдено / Замечание / Заблокировано / Пропущено / Не проверено;
- комментарии с автосохранением;
- замечания, вопросы и баги, привязанные к пункту;
- у бага — обязательные нумерованные **шаги воспроизведения**;
- URL активной вкладки;
- прогресс и компактная статистика;
- автосохранение;
- экспорт: TSV для Excel, текст для Jira, полный отчёт, JSON/TXT;
- **backup / restore** всех тестирований в один JSON-файл;
- светлая и тёмная тема по системным настройкам.

## Установка

```bash
cd Qa-Check-list
npm install
npm run build
```

Далее в Chrome:

1. Откройте `chrome://extensions`
2. Включите **Developer mode**
3. Нажмите **Load unpacked**
4. Выберите папку `dist`

Клик по иконке расширения открывает Side Panel.

Для разработки с hot reload:

```bash
npm run dev
```

## Использование

1. Создайте тестирование (название обязательно; Jira / окружение / версия — по желанию).
2. В режиме **Редактирование** добавьте пункты и подпункты (`Enter` быстро создаёт следующий).
3. Переключитесь в **Тестирование**.
4. Отмечайте статусы кнопками или клавишами `1`–`4`.
5. При необходимости добавьте комментарий, замечание, вопрос, баг или URL вкладки.
6. Нажмите **Завершить тестирование**.
7. Экспортируйте результат.

## Экспорт

| Кнопка | Что делает |
|--------|------------|
| **Копировать для Excel** | TSV в буфер → вставьте в Excel / Google Sheets (`Ctrl+V`) |
| **Копировать для Jira** | Читаемый plain text для комментария/описания в Jira |
| **Копировать всё** | Максимально полный текстовый дамп |
| **Скачать JSON** | Полный `TestRun` без потери данных |
| **Скачать TXT** | Jira-формат файлом |

Интеграций с API нет: только копирование и локальное скачивание.

## Backup и перенос на другое устройство

На главном экране:

1. **Скачать backup** — сохраняет все тестирования в файл `qa-check-list-backup-YYYY-MM-DD.json`.
2. На другом профиле/устройстве установите расширение.
3. **Восстановить из backup** — выберите файл. Текущие данные будут **полностью заменены** содержимым backup.

Перезапуск браузера и выключение компьютера данные не удаляют. Обычная очистка cookie/кеша сайтов тоже обычно не затрагивает storage расширения.

## Структура

```text
src/
  background/     — service worker (Side Panel on action click)
  domain/         — модели, дерево пунктов, статистика
  storage/        — chrome.storage.local
  export/         — Excel/Jira/Full/JSON
  sidepanel/      — React UI
```

## Разрешения

- `sidePanel` — основной интерфейс
- `storage` — локальное сохранение
- `tabs` — получение URL активной вкладки

Никаких host permissions и внешних сервисов.

## Проверка

```bash
npm run build
npm run verify
```

Скрипт `scripts/manual-verify.mjs` поднимает Chromium (Playwright), загружает `dist/` и проходит основной сценарий: создание чек-листа, вложенность, статусы, баг, экспорт Excel/Jira, persistence.
